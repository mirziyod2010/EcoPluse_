EcoPulse — версия сайта на HTML + CSS + JavaScript

КАК ЗАПУСТИТЬ
1. Распакуйте ZIP.
2. Откройте index.html двойным щелчком в Chrome, Safari или другом браузере.
3. Создайте профиль, выберите задания и отправляйте фотоотчёты.
4. В разделе «Проверка» можно включить демонстрационный режим администратора и одобрить отчёты.

СОСТАВ
index.html — сайт
styles.css — оформление
app.js — логика регистрации, заданий, отчётов, рейтинга
 tasks.js — 15 оригинальных экологических заданий из исходного проекта EcoPulse

ВАЖНО
Это полностью статическая автономная демонстрационная версия без Telegram, Node.js и Python.
Все данные хранятся в localStorage конкретного браузера. Участники на разных устройствах не видят друг друга. Фото хранятся в браузере; объём ограничен. Администратор не защищён серверной авторизацией.
Для настоящего общего сайта лицея потребуется подключить серверную базу данных, защищённые аккаунты и хранилище фотографий.
Шрифты загружаются из Google Fonts при наличии интернета; без интернета используются системные.
